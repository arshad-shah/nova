## Goal
The three `app:*` channels are live: `app:restart` relaunches the app,
`app:about-info` feeds the in-app About modal with v2-truthful runtime
versions in the v1 payload shape, and `app:action:result` has a
result-broker so the Phase-5 app-action round trip
(`app:action:perform` event → renderer → `app:action:result`) can plug in
without reshaping the channel.

## Acceptance criteria
- [ ] 1. `app:restart` relaunches via Tauri's restart API (v1:
      `app.relaunch(); app.exit(0)`). Covered by a handler-level test that
      asserts the restart hook is invoked (the actual relaunch is exercised
      in the phase-gate smoke matrix, not unit tests).
- [ ] 2. `app:about-info` returns the v1 field set — `name`, `version`,
      `electron`, `chrome`, `node`, `v8`, `os`, `arch` — with the same keys
      (the renderer's AboutModal reads them; the contract is frozen).
      `name`/`version` come from the Tauri app config; `os`/`arch` from the
      OS; the runtime-version fields carry the v2 equivalents (Tauri/wry/
      WebView versions) as *values* under the existing keys, with the exact
      mapping decided against `AboutModal.tsx`'s labels and recorded in the
      Log. No key is added, renamed, or dropped.
- [ ] 3. `app:action:result` accepts
      `{ requestId, success, error? }` and resolves the matching pending
      request in an in-core broker (map of requestId → oneshot responder).
      A result for an unknown/expired requestId is a silent no-op. In v1
      this handler lives in the AI plugin; here the broker is host-owned
      plumbing that the Phase-5 AI crate (T-504) consumes — document the
      handoff in code.
- [ ] 4. The broker expires pending requests (configurable timeout,
      defaulting to the v1 app-action timeout found in the AI plugin —
      verify against `src/main/plugins/bundled/ai/` and record it) so an
      abandoned action can't leak entries.
- [ ] 5. Contract fixtures for `app:restart` (void), `app:about-info`
      (response shape), and `app:action:result` round-trip byte-stably.
