## Acceptance criteria
- [ ] 1. Full standing gates green over the whole workspace: `cargo fmt
      --check`, `cargo clippy --workspace --all-targets -- -D warnings`,
      `cargo test --workspace`, `pnpm exec tsc -b --noEmit`, `pnpm exec vitest run --project unit`,
      contract drift check (regenerated bindings, `git diff --exit-code`).
- [ ] 2. Export/import parity suite green against the seeded test DBs: csv and
      json exports byte-identical to v1 goldens; sql export goldens green
      per-dialect; import fixtures (csv→table, sql script) produce identical
      row outcomes on both stacks. Command transcript in the report.
- [ ] 3. Theme parity: screenshot diff of the theme gallery story across
      **all** core themes shipped by T-403 (10 as of themes-data.ts) is
      pixel-identical between v1 capture and Tauri run; diff artifacts
      referenced from the report.
- [ ] 4. Attack fixtures (adversarial cases, run — not reviewed): zip-slip
      archive, absolute/drive-letter entries, symlink archive, bundled
      name-collision, path-separator plugin name — every one rejected, with
      filesystem-state assertions proving nothing escaped, transcript in the
      report.
- [ ] 5. A sample declarative third-party plugin installs from zip, activates,
      contributes a theme + connection fields end-to-end, survives restart,
      uninstalls cleanly (T-407's e2e scenario re-run by the verifier).
- [ ] 6. Channel burndown regenerated: every `plugins:*` (22), `themes:*` (1),
      `export:*`/`import:*` row is `migrated`; report lists the remaining
      `not_migrated` count (expected: ai/mcp/updater domains only).
- [ ] 7. Smoke matrix: `cargo tauri dev` boots and `cargo tauri build`
      packages on the platforms available to the swarm; the report documents
      exactly which platforms ran (no claims for platforms that didn't).
- [ ] 8. Report committed as
      `specs/tauri-migration/tasks/gate-reports/phase-4-<date>.md` with
      command transcript summaries, exit codes, and a verdict; INDEX.md
      status updated in the same commit by the orchestrator.
