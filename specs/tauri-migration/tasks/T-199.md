## Goal
Phase 1's exit criteria are verified with evidence and committed as
`specs/tauri-migration/tasks/gate-reports/phase-1-<date>.md`: the React app
boots inside Tauri, every `window:`-domain channel works (two `wontport`
excepted), everything else returns `NOT_MIGRATED`, and the manual window/menu
parity checklist has been executed step-by-step with recorded results. Phase 2
does not open until this report is green.

## Acceptance criteria
- [ ] 1. Full standing gates pass and are transcribed: rust
      (fmt/clippy/test, whole workspace) and renderer (typecheck + unit
      project + affected story tests), plus the contract drift check and
      the round-trip fixture tests (T-103), plus the T-005 parity case
      still green against v1.
- [ ] 2. Burndown audit: `channel-burndown.md` regenerated and shows
      `migrated` for exactly the Phase 1 set (T-105's five window channels,
      T-108's six, `window:edit-role` as renderer-local per T-107), the two
      `wontport` rows, and `not_migrated` for everything else; a grep of
      dispatch stubs matches the table.
- [ ] 3. Boot proof: `pnpm dev:tauri` on the dev machine reaches the app
      shell (screenshot in report); renderer console shows only
      `NOT_MIGRATED` failures for unported domains — no crashes, no blank
      window.
- [ ] 4. **Manual window/menu parity checklist**, each step executed and
      marked pass/fail/not-run-on-this-platform:
      (a) frameless drag: dragging the title bar's empty area moves the
          window; dragging a button does not;
      (b) maximize: double-click the bar and click the maximize control —
          both toggle, and the control's icon reflects state each time
          (`window:maximize-changed` observed for an OS-initiated snap
          too);
      (c) menu accelerators fire: Cmd/Ctrl+T (new tab), Cmd/Ctrl+F (find),
          Cmd+, on macOS (settings) each reach their `menuActions` handler;
      (d) rebind moves accelerator: change a keybinding via T-106's
          rebuild API (dev trigger — `settings:set` wiring is T-202), old
          accelerator dead, new one fires;
      (e) About opens the in-app `AboutModal` from the menu on this
          platform (never a native panel);
      (f) open-external: an `https://` link opens the default browser; a
          `file://` URL does nothing;
      (g) devtools toggle opens/closes devtools via menu item and channel;
      (h) file drop: dropping a file anywhere forwards its OS path
          (observed in trace) even though the handler answers
          `NOT_MIGRATED`.
- [ ] 5. Smoke matrix: which platforms (macOS/Windows/Linux) each check
      actually ran on is tabulated; unexercised platforms are named as
      debt, not claimed.
- [ ] 6. Verifier implemented none of T-101..T-109; report ends with
      `GATE: green` or `GATE: red — <blockers>`; committed by the
      orchestrator; INDEX.md shows all Phase 1 tasks `done`.
