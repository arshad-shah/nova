## Goal
The ecosystem assumptions are already pre-researched: `decisions/
versions-baseline.md` (researched 2026-07-16) is the verified digest the
ADRs are written against. This task **verifies that baseline for drift** at
execution time — crates.io checks and changelogs since 2026-07-16 — pins
the result in `decisions/versions.lock.md`, and amends the drifted ADRs
*and the baseline file*; it does not re-research from scratch.

## Acceptance criteria
- [ ] 1. `versions.lock.md` exists and pins, for every row of
      versions-baseline.md — Tauri 2.x current minor; the plugins
      `tauri-plugin-dialog`, `-opener`, `-notification`, `-os`, `-updater`,
      `-single-instance`, `-window-state`; `rmcp`; `keyring`; `russh`;
      `mysql_async`; `mongodb`; `redis`; `rusqlite`; `tokio-postgres`;
      `ts-rs`; `wry` — the exact version at execution time, check date +
      source (crates.io / GitHub release), and the baseline value it is
      compared against, with a drift verdict (unchanged / patch / breaking).
- [ ] 2. For each drifted entry, the changelog since 2026-07-16 is scanned
      for breaking changes / deprecations affecting our usage; any
      newly-abandoned crate names a replacement candidate and amends ADR-0004.
- [ ] 3. The baseline's load-bearing capability claims are re-confirmed (or
      drift recorded), with citations:
      (a) tauri-bundler still has **no native MSIX** (issues #4818/#8548) —
      feeds ADR-0008's EXE/MSI-linked Store path + T-008;
      (b) rmcp is still **Streamable-HTTP-only** (legacy SSE removed in
      v0.11.0; no re-addition) — feeds ADR-0006/T-506;
      (c) `keyring` v4 split (keyring-core + per-platform store crates;
      Linux dbus-secret-service sync baseline) still current — feeds
      ADR-0007/T-203;
      (d) wry's WebView engine + minimum version per OS (WebView2 /
      WKWebView / **webkit2gtk-4.1**) — feeds T-009's test matrix.
- [ ] 4. Every drifted ADR claim AND the affected versions-baseline.md rows
      get an appended amendment (never a rewrite) referencing this task;
      unchanged ADRs are listed as re-verified in the Log.
- [ ] 5. Findings that change a *decision* (not a detail) are flagged for
      human ratification via T-001, named explicitly in the Log.
