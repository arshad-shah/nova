## Goal
The documentation set describes v2 reality: Tauri process model, Rust crate
map, the frozen IPC contract's new backend, declarative plugins, and the
cargo/tauri toolchain — in docs/, their site/ counterparts (CLAUDE.md rule:
same change), and CLAUDE.md itself, so the docs-are-source-of-truth-for-intent
convention survives the migration.

## Acceptance criteria
- [ ] 1. `docs/architecture.md` rewritten: Tauri 2.x shell (tao/wry/OS
      WebView), Rust core process + tokio concurrency model, the
      `ipc_dispatch` single-command bridge and `backend-bridge.ts` shim,
      the src-tauri/crates/* map (mirroring 02-target-architecture but
      describing what shipped), the preserved ownership boundary
      (orchestrator vs contribution crates), and the fixed SQLite-blocking
      defect. `docs/diagrams.md` regenerated so every Mermaid diagram shows
      v2 processes/flows (no `src/main/` boxes remain).
- [ ] 2. Every subsystem doc affected by the port is updated: plugins.md
      (declarative model, sdkTarget, WASM horizon per ADR-0003),
      plugin-security.md (new trust model: compiled-in bundled code,
      no-execution third-party, install guards), ipc.md (adding a channel now
      means shared/ipc.ts + Rust dispatch + drift check), ai.md — and every
      MCP setup page (docs/ + site/) changes endpoint/transport to
      **Streamable HTTP at `/mcp`** with updated client-config examples
      (legacy `/sse`+`/messages` gone — ADR-0006 consequences), settings.md,
      notifications.md, activity.md, tab-persistence.md, onboarding.md
      (+ a What's New release page for v2 per its authoring instructions),
      docs/sdk/ (compatibility notice: `@verql/plugin-sdk` v1-line has no v2
      host, per ADR-0003 consequences).
- [ ] 3. site/src/content/docs/ counterparts updated in the same change for
      every doc touched in 1–2 (guide + develop/plugins pages, the SDK
      compatibility notice included); `site` builds clean.
- [ ] 4. CLAUDE.md rewritten for v2: the Commands section reflects the real
      toolchain (`cargo tauri dev`, `cargo tauri build`, `cargo test
      --workspace`, `cargo clippy`, `pnpm test` for the renderer/stories,
      `scripts/test-dbs.sh` unchanged); architecture/process-model/plugin
      sections describe crates not `src/main/`; the ownership-boundary and
      DB-agnostic-language rules restated for Rust contribution crates; the
      doc list matches the post-rewrite docs/ set.
- [ ] 5. Doc-reality cross-checks pass: every file path referenced in the
      rewritten docs exists in the repo (scripted link/path check); a grep
      over docs/ + CLAUDE.md + site/ for `src/main/`, `electron-vite`,
      `electron-builder`, `window.electronAPI` (as current-behavior claims)
      returns only historical/changelog/migration-spec mentions.
- [ ] 6. No feature-work smuggling: docs describe shipped v2 behavior only;
      anything aspirational is marked as post-cutover (ADR-0003 WASM SDK,
      signing) — an adversarial reviewer diffs docs claims against task Logs.
