## Goal
v1 forwards OS file drops to `plugins:drag-drop` by reading Electron-only
`File.path` off the HTML5 drop event — a property that does not exist in any
Tauri WebView. Under Tauri the same forwarding runs off the webview drag-drop
event's native paths; under Electron the existing path keeps working
unchanged until cutover.

## Acceptance criteria
- [ ] 1. Under Tauri, the hook subscribes to the webview drag-drop event
      (`onDragDropEvent` drop case) through the bridge seam — the hook
      itself stays shell-agnostic; only `backend-bridge.ts` (or a helper it
      exposes) knows the Tauri API.
- [ ] 2. Behavior parity with the v1 hook: every dropped file's **absolute
      OS path** is forwarded as one
      `invoke(IPC_CHANNELS.PLUGINS_DRAG_DROP, path)` call per file
      (multi-file drops forward each), failures swallowed exactly as v1's
      `.catch(() => {})` — in Phase 1 the channel returns `NOT_MIGRATED`
      and the drop is a visible no-op, which is correct until T-407.
- [ ] 3. Under Electron, the existing DOM `dragover`/`drop` +`File.path`
      path is preserved verbatim; no double-forwarding can occur on either
      shell (exactly one mechanism active per shell, asserted in tests).
- [ ] 4. `tauri.conf.json` enables the webview drag-drop event (`dragDrop`
      config). The known trade-off — with native drag-drop interception
      enabled, HTML5 file-drop DataTransfer stops seeing files, and on
      Windows it can affect HTML5 DnD generally — is checked against the
      app's internal drag-and-drop surfaces; findings recorded in the Log
      (a broken internal DnD is an escalation, not a footnote).
- [ ] 5. Evidence in the Log of a real drop under `tauri dev` on the dev
      platform: the traced dispatch shows `plugins:drag-drop` invoked with
      the OS path (the T-102 tracer logs channel names — sufficient).
- [ ] 6. Unit tests: given a fake bridge emitting a drop with two paths, the
      hook invokes the channel twice with the right arguments; given the
      Electron environment, the DOM path fires and the Tauri subscription
      does not.

## Notes
- The channel constant is `IPC_CHANNELS.PLUGINS_DRAG_DROP`
  (`'plugins:drag-drop'`); the string-literal-channel CI test applies to
  any new call site.
- `backend-bridge.ts` is shared turf with T-107 — the orchestrator
  serializes them (touches intersect by design; both extend the Tauri-side
  seam T-104 created).
- Do not try to make `plugins:drag-drop` do anything server-side here —
  its Rust implementation is Phase 4 (T-407); this task is only the
  renderer/event seam.
