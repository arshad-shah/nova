## Goal
Phase 5's exit criteria (03-migration-strategy §Phase 5 gate) are proven with
transcripts and committed as `gate-reports/phase-5-<date>.md`. This is the
"backend feature-complete" gate: after it, only updater/packaging/cutover
work remains and the `NOT_MIGRATED` burndown is at zero.

## Acceptance criteria
- [ ] 1. Full standing gates green over the whole workspace (rust + renderer
      + contract scopes, commands and exit codes in the report).
- [ ] 2. Stream-replay corpus: every recorded v1 `ai:chat:event` fixture
      (minimum: plain chat, multi-round tool loop, blocked write in
      read-only, approval approved, approval rejected, provider error, abort)
      replays identically from the Rust side with mocked providers — event
      types, field shapes, ordering, terminal semantics; per-case allowlists
      (ids/timestamps) only. `ai:explain:event` fixtures included.
- [ ] 3. Live MCP client test (ADR-0006): Claude Code connects to the Rust
      server over the SSE endpoints, lists the gated tool set, executes a
      read tool (`list_tables`) against a seeded DB, and a write tool call
      round-trips approval — renderer prompt + OS notification surfaced,
      approve executes, deny rejects, timeout auto-denies. Transcript (client
      output + server activity entries) in the report.
- [ ] 4. Channel burndown regenerated: `not_migrated` count is **zero** —
      all 143 invoke channels are `migrated` or `wontport` (exactly
      `window:menu:list` + `window:menu:popup`), and all 15 events are
      emitted from Rust. The full table is embedded or linked in the report.
- [ ] 5. Complete parity suite implemented so far (drivers, config, appdata,
      export/import, plugins, ai, mcp) green against the seeded test DBs —
      including error-parity cases.
- [ ] 6. Adversarial spot-checks run: MCP unauthorized request → 401,
      rebound-Host request → 403, AI key set leaves no secret in config.json,
      `explain_query` smuggling `EXPLAIN ANALYZE DELETE` prompts for
      approval on both AI and MCP surfaces.
- [ ] 7. Smoke matrix: `cargo tauri dev` boot + `cargo tauri build` on the
      platforms available; report documents which platforms actually ran.
- [ ] 8. Report committed as
      `specs/tauri-migration/tasks/gate-reports/phase-5-<date>.md`; INDEX.md
      updated in the same commit by the orchestrator.
