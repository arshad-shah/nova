## Goal
The Electron implementation is deleted: `src/main/`, `src/preload/`, the
Electron build chain, and every main-process-only npm dependency are removed;
CI runs the v2 pipeline only; the repo builds, tests, and boots as a pure
Tauri app. v1 remains recoverable via git history and the last v1 release tag
only.

## Acceptance criteria
- [ ] 1. `src/main/**`, `src/preload/**`, and `electron.vite.config.ts` are
      deleted; no source file imports from them (typecheck + grep prove it);
      the renderer builds via the Vite config the Tauri scaffold established.
- [ ] 2. package.json contains **none** of: electron, electron-vite,
      electron-builder, @electron/rebuild, better-sqlite3, pg, mysql2,
      mongodb, ioredis, snowflake-sdk, ssh2, @modelcontextprotocol/sdk,
      csv-parse, csv-stringify, nor their @types/* companions; the
      `build` field (electron-builder config, incl. the appx block — its
      identity now lives in T-604's packaging) and `postinstall`
      electron-rebuild are removed; remaining main-only deps audited (e.g.
      sql-formatter stays only if packages/plugin-sdk or the renderer
      actually imports it — grep evidence in the Log). pnpm-lock.yaml
      regenerated; `pnpm install` clean.
- [ ] 3. Scripts rewritten: `dev`/`build`/`build:mac|win|linux` drive
      cargo-tauri (matching CLAUDE.md as rewritten by T-607); no script
      references electron*.
- [ ] 4. Tests updated: unit tests importing `src/main/**` are deleted (their
      Rust ports exist per earlier tasks) or moved; the renderer test stubs
      of `window.electronAPI` keep working through the bridge shape (04-ipc
      §rollout); `pnpm test -- --run` and story tests green.
- [ ] 5. CI cleanup: Electron build/test jobs removed; the pipeline is rust
      standing gate + renderer gate + contract drift check + per-platform
      bundle jobs; all green on the integration branch.
- [ ] 6. Contract cleanup at cutover (04-ipc §freeze discipline): the two
      `wontport` channels (`window:menu:list`, `window:menu:popup`) are
      deleted from shared/ipc.ts and the Rust dispatch; the burndown table
      reflects it; no other channel is added/removed/reshaped.
- [ ] 7. Repo-wide `grep -ri electron` hits only: historical docs/changelog
      entries, the migration spec (specs/tauri-migration/**), CHANGELOG,
      release-notes pages, and git history — no build config, no source, no
      dependency. The hit list is attached to the Log.
- [ ] 8. Post-deletion smoke: `cargo tauri dev` boots, the full parity suite
      still passes (it can no longer compare against a live v1 — golden
      files remain the oracle), and `cargo tauri build` bundles on the
      available platforms.
