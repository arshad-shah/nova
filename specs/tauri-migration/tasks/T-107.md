## Goal
v1's `window:edit-role` channel calls Electron
`webContents.undo()/redo()/cut()/copy()/paste()/selectAll()` — Chromium-level
editing commands that work in Monaco and any focused input. Tauri has no
equivalent (inventory hotspot 6), so the behavior is reimplemented at the
DOM/Monaco level and wired into the Tauri bridge path, leaving
`menu-model.tsx` and the Electron path untouched.

## Acceptance criteria
- [ ] 1. `lib/edit-roles.ts` exports `performEditRole(role)` for exactly the
      six v1 roles (`undo | redo | cut | copy | paste | selectAll` — the
      literal union from `src/main/ipc/window.ts`).
- [ ] 2. Focused-Monaco dispatch: when the active element belongs to a
      registered editor (`stores/editor.ts` registry), roles run through
      Monaco's own actions/triggers (undo/redo/select-all and
      clipboard actions), so editor undo stacks behave exactly as under v1.
- [ ] 3. Plain inputs/textareas: roles work in non-Monaco fields (connection
      form, search boxes) via the DOM editing APIs; paste uses
      `navigator.clipboard.readText()` where the WebView permits — the
      WebKitGTK/WKWebView clipboard caveats from the T-009 report are
      handled or explicitly documented as platform limitations in the file
      header (never a silent no-op: a denied paste surfaces a toastable
      error).
- [ ] 4. Under Tauri, `invoke('window:edit-role', role)` routes to
      `performEditRole` locally in the bridge — `menu-model.tsx` keeps its
      single implementation and zero diffs; under Electron the channel
      still reaches the v1 handler. The Rust dispatch arm keeps its
      `NOT_MIGRATED` stub, and the burndown row is annotated
      `migrated (renderer-local)` so the metric doesn't lie.
- [ ] 5. macOS native Edit-menu items (muda predefined undo/redo/cut/copy/
      paste/selectAll from T-106) are documented as the primary macOS path
      (first-responder chain); this implementation backs the Win/Linux
      app-drawn bar. No double-execution: an action fires exactly once per
      activation on every platform.
- [ ] 6. Unit tests cover: role→Monaco-trigger mapping with a fake editor
      registry entry, input-element fallback selection, and the unknown-
      focus no-crash path.
