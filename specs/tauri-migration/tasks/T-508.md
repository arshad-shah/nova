## Goal
The attention hub's events (T-207) surface as native OS notifications via
tauri-plugin-notification with the v1 dispatcher's policy intact: the same
three user settings, focus suppression, per-id dedupe/replace, and dismissal
when the underlying request resolves.

## Acceptance criteria
- [ ] 1. The dispatcher policy ports as a pure module (native layer injected,
      unit-testable without Tauri): `is_available` = enabled setting AND OS
      support; `only_when_unfocused` suppression when any app window is
      focused; per-id replace (same correlation id closes the prior
      notification first); `resolved` attention events dismiss the matching
      live notification; approval-kind events gated by `notifyApprovals` and
      presented with urgency critical; alert→alert, everything else→info;
      default click action focuses the primary window.
- [ ] 2. Settings gates read live (not cached at boot) from the same keys the
      v1 plugin used — `plugins.verql-plugin-os-notifications.{enabled,
      onlyWhenUnfocused, notifyApprovals}`, defaults all true — so a
      migrated v1 config keeps the user's toggles and `plugins:get-settings`
      still surfaces the schema (coordinate with T-407's settings handlers).
- [ ] 3. Attention-hub subscription: subscribes to the T-207 hub at app
      setup; AI approvals (T-503/T-504), MCP approvals (T-507), and alerts
      all arrive through this one seam — no notification call-sites anywhere
      else (grep-checked: tauri-plugin-notification referenced only from this
      module).
- [ ] 4. Focus detection via Tauri window focus state, equivalent to v1's
      `BrowserWindow.getAllWindows().some(isFocused)` — any focused app
      window suppresses (when the setting is on), not just the main window.
- [ ] 5. Dismissal capability honestly handled: v1 could programmatically
      close notifications (Electron handle.close()). If
      tauri-plugin-notification cannot dismiss on a platform, the dispatcher
      still drops its handle-tracking (no leak) and the limitation is
      documented in the module docs + Log — never silently pretended.
- [ ] 6. Unit tests port the dispatcher matrix: disabled → no-op handle;
      focused+onlyWhenUnfocused → suppressed; approval with notifyApprovals
      off → suppressed; same-id replace; resolved → dismissed; dispose closes
      all live handles.
