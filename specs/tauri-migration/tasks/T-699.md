## Goal

## Acceptance criteria
- [ ] 1. **Task graph complete**: every task in tasks/ is `done` in both the
      task files and INDEX.md (they must agree; task files win on conflict);
      gate reports for phases 0–5 exist and are green.
- [ ] 2. **Full parity suite passes on all six drivers** (sqlite, postgresql,
      mysql, mongodb, redis, snowflake) against the seeded test databases,
      **including the error-parity cases** (wrong password, dead host, syntax
      error, constraint violation, timeout — DbErrorCode classification and
      message shape) — re-run now, transcript in the report.
- [ ] 3. **Data migration verified on macOS, Windows, and Linux** from a real
      v1 install (config.json, credentials.enc, app.db): connections,
      settings, saved queries, history, open tabs, conversations, and secrets
      present and functional post-import; per-OS evidence (T-605's flow) —
      platforms actually exercised are named; any un-exercised platform is a
      FAIL, not a footnote.
- [ ] 4. **Performance guardrails at-or-better vs the v1 baseline**: cold
      start, 100k-row execution→grid + peak RSS, idle RSS, per-platform
      bundle sizes (baseline-v1.md vs baseline-v2.md, T-606) — spot-re-run at
      least cold start and the 100k-row case; regressions only pass with an
      explicitly accepting ADR.
- [ ] 5. **Packaging artifacts installable**: macOS dmg installs + launches
      and the rendered Homebrew cask is valid; Windows package per the
      ADR-0008 outcome installs + launches; Linux AppImage launches on a
      clean distro — checksums recorded.
- [ ] 6. **Human sign-off recorded**: every ADR in decisions/ is `accepted`,
      and the cutover checklist (T-609) carries the owner's sign-off with no
      unaccepted OPEN items.
- [ ] 7. Standing gates re-run green at the final SHA: rust + renderer +
      contract scopes, and `NOT_MIGRATED` is absent from the codebase
      (grep) with the burndown showing zero `not_migrated`.
- [ ] 8. Final report committed as
      `specs/tauri-migration/tasks/gate-reports/phase-6-final-<date>.md`
      with: per-criterion verdicts, command transcripts + exit codes,
      platforms exercised, artifact checksums, and the overall verdict.
      INDEX.md updated by the orchestrator in the same commit.
