      least one golden case against v1 — the T-005 verify command run
      fresh, transcript in the report.

      (typecheck + unit) and the rust-ci workflow (in its graceful-skip
      state — `src-tauri/` doesn't exist yet) on the integration branch is
      green; run URLs or local-equivalent transcripts recorded.
- [ ] 5. **Baseline recorded**: `tests/parity/baseline-v1.md` exists with
      all four metric groups (T-004 criteria) present.
- [ ] 6. Every Phase 0 task is `done` in `INDEX.md`; open escalations from
      the spikes (Snowflake SSO gap, MSIX rung, macOS secrets path) are
      listed in the report with their human decisions — an undecided

      `GATE: red — <blockers>`); only the orchestrator commits it.
